3. D2가 무엇인지 확인

대화 중 D2가 무엇인지 질문했고, Arduino UNO의 Digital Pin 2, 즉 보드에 숫자 2라고 적힌 디지털 핀이라는 점을 확인했다.

D2 = 디지털 2번 핀. 같은 방식으로 D8은 8번, D10은 10번 핀이다.

4. 스위치 확인과 수정 과정

초기 판단처음 사진만 보고 COM / NO / NC 방식의 3단자 스위치로 설명했다.
추가 사진 확인실제 부품은 4핀 푸시버튼이라는 점을 확인했다.
최종 정리4핀 중 서로 반대쪽에 있는 핀 2개만 사용하고 나머지 2개는 사용하지 않아도 된다.
4핀 버튼은 보통 같은 쪽 두 핀이 내부적으로 연결되어 있다. 따라서 한쪽 그룹의 핀 1개 + 반대쪽 그룹의 핀 1개를 사용해야 버튼을 눌렀을 때 입력이 바뀐다.

6. 신호등 기본 코드

버튼을 누르면 노랑 3초 → 빨강 10초 → 다시 초록으로 돌아오는 구조를 만들었다.

const int greenLED = 10;
const int yellowLED = 9;
const int redLED = 8;
const int buttonPin = 2;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);

  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
}

void loop() {
  if (digitalRead(buttonPin) == LOW) {
    digitalWrite(greenLED, LOW);

    digitalWrite(yellowLED, HIGH);
    delay(3000);
    digitalWrite(yellowLED, LOW);

    digitalWrite(redLED, HIGH);
    delay(10000);
    digitalWrite(redLED, LOW);

    digitalWrite(greenLED, HIGH);

    while (digitalRead(buttonPin) == LOW) {}
    delay(100);
  }
}

7. 초록불이 안 켜졌던 문제

초록불이 켜지지 않는 상황이 있어, 코드 문제인지 배선 문제인지 분리해서 확인하기 위해 각 색을 2초씩 켜는 테스트 코드를 사용했다.

void loop() {
  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
  delay(2000);

  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, HIGH);
  digitalWrite(redLED, LOW);
  delay(2000);

  digitalWrite(greenLED, LOW);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, HIGH);
  delay(2000);
}

8. 빨간불에 부저 추가

빨간불이 켜져 있는 10초 동안 부저가 소리 나도록 확장했다. 부저의 +는 D7, -는 GND로 연결했다.

처음에는 단순한 빠른 삐삐삐 반복음으로 시작했고, 이후 리듬을 묶거나 더 빠르게 만들고, 응원가나 게임 비트처럼 들리게 만드는 방향으로 발전시켰다.

9. 부저 패턴 실험

단순 반복음빨간불 10초 동안 일정한 간격으로 삐삐삐삐 반복.
묶음 리듬삐삐삐 / 삐삐삐 / 삐삐삐삐 / 삐삐삐 형태.
초고속 반복약 60ms 소리 + 40ms 무음으로 빠른 경고음 구현.
야구 응원가 느낌NC 다이노스 블레인 응원가처럼 긴 음 + 짧은 반복음 구조를 시도.
유명 비트 방향마리오 같은 게임풍 비트나 사람들이 바로 알아챌 만한 짧은 리듬을 원했고, '빠빠빠밤' 같은 비트도 예시로 실험했다.

10. 현재 기준 통합 코드 예시

아래 코드는 지금까지의 회로를 한 번에 실행할 수 있는 기본 통합형이다. 빨간불 동안 짧은 비트가 반복된다.

const int greenLED = 10;
const int yellowLED = 9;
const int redLED = 8;
const int buzzer = 7;
const int buttonPin = 2;

void setup() {
  pinMode(greenLED, OUTPUT);
  pinMode(yellowLED, OUTPUT);
  pinMode(redLED, OUTPUT);
  pinMode(buzzer, OUTPUT);
  pinMode(buttonPin, INPUT_PULLUP);

  digitalWrite(greenLED, HIGH);
  digitalWrite(yellowLED, LOW);
  digitalWrite(redLED, LOW);
}

void loop() {
  if (digitalRead(buttonPin) == LOW) {
    digitalWrite(greenLED, LOW);

    digitalWrite(yellowLED, HIGH);
    delay(3000);
    digitalWrite(yellowLED, LOW);

    digitalWrite(redLED, HIGH);
    unsigned long startTime = millis();

    while (millis() - startTime < 10000) {
      tone(buzzer, 900); delay(120); noTone(buzzer); delay(130);
      tone(buzzer, 900); delay(120); noTone(buzzer); delay(130);
      tone(buzzer, 1500); delay(300); noTone(buzzer); delay(300);
    }

    noTone(buzzer);
    digitalWrite(redLED, LOW);
    digitalWrite(greenLED, HIGH);

    while (digitalRead(buttonPin) == LOW) {}
    delay(100);
  }
}

11. 핵심 요약

  • 신호등은 G=10, Y=9, R=8.
  • 4핀 버튼은 서로 반대쪽 핀 2개를 사용해 D2와 GND에 연결.
  • INPUT_PULLUP 사용으로 버튼을 누르면 입력이 LOW가 된다.
  • 초기 상태는 초록불.
  • 버튼 입력 후 노랑 3초 → 빨강 10초 → 다시 초록.
  • 빨간불 동안 부저(D7)에서 원하는 리듬 출력 가능.
  • 현재 원하는 발전 방향은 마리오 같은 알아듣기 쉬운 8비트/유명 비트 느낌.
